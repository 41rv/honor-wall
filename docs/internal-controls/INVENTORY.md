جرد المصدر يحوي155 تصريح JSX ثابتًا:109 أزرار و12 قائمةSelect و14 حقلinput و3textarea و10summary و7GlassChoices. هذا عدد مواضع الشيفرة، وليس عدد العناصر المعروضة ديناميكيًا؛ كثير منها يتكرر لكل سجل. [التفصيل الآلي بموضع كل تصريح](control-declarations.json).

## النظام المشترك

- سبعة مواضع فعلية تستخدم `GlassChoices`: المشاريع، فلاتر المهام، الأفكار، حالة المهمة، حالة الخطوة، أقسام التقدم، نطاق الفترة. المكون يحافظ على عناصر button وترتيبها وإجراءاتها، ويضيف مؤشرًا زخرفيًا غير قابل للنقر أو التركيز، وaria-pressed عند غياب دلالة الاختيار.
- يتحرك المؤشر وحده عبرtransform لمدة190ms، وتنتقل ألوان وحدود التحكم170ms. لا تتحرك محتويات القوائم أو الصفوف. ResizeObserver يتابع تغيّر الحجم والخط والتفاف الخيارات، ويُفصل عند تغيير المكون أو إزالته.
- CSS variables مشتركة للخامة والحواف والتحديد والنص والثيمين. تمويه3px على مسار اختيار مستقل فقط؛ لا تمويه متداخل داخلsurface، ولا SVG أو مرشحات على الحقول أو الأزرار المتكررة أو الجداول الطويلة. قوائم الإجراءات الصغيرة تستخدم4px.

## الاستثناءات المقصودة

الأزرار الأساسية خضراء واضحة، والخطرة بلون التحذير، والإنجاز وألوان أيزنهاور والتعطيل كما كانت. حقول النص والملاحظات والتاريخ/الوقت والـSlider تحتفظ بأسطح مقروءة. قوائم select المنبثقة تخص النظام/المتصفح: حُسّن عنصرها المغلق دون استبدالها بقوائم مخصصة أو الادعاء بتحريك نافذة Android الأصلية. بطاقات الإحصاء والرسوم ليست عناصر اختيار؛ لم تُحوّل إلى أزرار زجاجية. لم يتغير ترتيب الخيارات أو إعدادات السماء أو الأشرطة أو Safe Areas أو البيانات.
